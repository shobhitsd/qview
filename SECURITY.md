# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of QView and post-quantum cryptographic governance seriously. If you discover a security vulnerability within QView, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email describing the vulnerability, proof of concept, and affected versions to `security@qview.internal` or via GitHub Private Vulnerability Reporting.
3. You will receive an initial response within 48 hours.
4. Coordinated disclosure will occur following the release of an official patch.
